# 数据结构树与 LeetCode 练习（C 语言）

一份以 C 语言实现为主的二叉树/树专题笔记，配套 7 个可独立编译运行的验证 demo。

## 写在前面

这份笔记从 2026 年国庆开始，到 10 月 17 日完成，前后大约半个月。

线性表部分相对好拿下，但树这一块的算法实现起来要难得多：指针、递归、参数传递、内存管理都更绕。树也是从线性结构走向图的一座桥——把树的遍历、搜索、递归和树形 DP 吃透，再去看图会顺很多。

## 文档

- [PDF 阅读版](notes/tree_leetcode_structures_in_c.pdf)（GitHub 可直接在线预览，也可下载）

正文 55 页，覆盖：

1. **树的遍历**：前/中/后序递归与非递归、Morris 遍历、层序及变式、N 叉树、由遍历序列还原二叉树
2. **树的搜索**：DFS（路径、结构判断、深度、树形 DP、祖先）、BFS、BST（增删查、验证、第 K 小、LCA、剪枝）
3. **树的结构与性质**：基本概念、特殊二叉树、堆、对称/镜像、子树/同构、直径/最大路径和、合并
4. **树上的动态规划**：自底向上/自顶向下、打家劫舍、最大路径和、监控二叉树状态机 DP

## 编译与运行

需要 gcc（MinGW-w64 或 Linux 均可）。以 LC103 为例：

```bash
cd demos/lc103_zigzag_fuzz
gcc -O2 -Wall -Wextra -o lc103_fuzz lc103_fuzz.c
./lc103_fuzz
```

Windows 下生成 `lc103_fuzz.exe`，运行 `./lc103_fuzz.exe`。其余 demo 的源文件名和命令见各自 README。
